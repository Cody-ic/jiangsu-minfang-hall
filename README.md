# 虚拟民防体验馆

江苏省民防体验馆参观纪实科普站 —— 把馆内的互动展项搬到网页上，不只是看文字，而是真的按一按、听一听、拖一拖。

🔗 **在线体验：[https://cody-ic.github.io/jiangsu-minfang-hall/](https://cody-ic.github.io/jiangsu-minfang-hall/)**

## 展项列表

| 展项 | 玩法 |
| --- | --- |
| 🧩 法规知识问答墙 | 12 道人防法规选择题，选完立刻看对错 |
| 🕰️ 国防建设成就时间轴 | 点年份节点，了解人民防空与国防教育的历史里程碑 |

| 🧯 灭火挑战 | 限时点击扑灭不断蔓延的火苗 |
| 🏚️ 地震反应速度挑战 | 预警倒计时后拼手速点击"就地避险" |
| 🔺 地震避险选位 | 房间图里选出地震时最安全的位置 |
| 🫀 心肺复苏训练台 | 连续点击/敲空格，实时测算按压频率 |
| 🔀 急救步骤排序 | 把急救处置步骤拖选排对 |

| ☢️ 辐射安全三原则 | 拖动距离/屏蔽/时间三个控件，感受辐射防护原理 |
| 🧰 民防装备认一认 | 装备图标与用途连线配对 |

| 🎒 应急背包打包挑战 | 背包容量有限，选出真正该带的应急物资 |

走完展项会在浏览器本地记录进度，前往 `passport.html` 可生成个性化的"民防体验官"证书并下载。

## 技术实现

纯静态 HTML + CSS + 原生 JavaScript，无构建工具、无外部依赖，双击 `index.html` 即可本地打开。

```
江苏省民防体验馆/
├── index.html          展馆地图首页
├── passport.html        体验官证书页
├── exhibits/             15 个展项页面
├── css/style.css         全站共享样式
└── js/                   公共脚本 + 各展项逻辑（js/common.js 管理 localStorage 进度）
```

## 本地运行

```
git clone https://github.com/Cody-ic/jiangsu-minfang-hall.git
cd jiangsu-minfang-hall
# 直接用浏览器打开 index.html 即可，无需安装依赖
```
